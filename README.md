# phg1024/tap

Homebrew casks for apps by Peihong Guo.

```bash
brew install --cask phg1024/tap/cadabra
```

| Cask | App |
|---|---|
| `cadabra` | [Cadabra](https://phg1024.github.io/Cadabra/): on-device dictation for macOS. Hold a key, speak, and the text appears at the cursor. |

Cadabra isn't notarized by Apple yet: the first time it opens, allow it under System Settings ›
Privacy & Security › **Open Anyway**.
